# Frontend

## Current State

- The browser-extension frontend is a WXT **side panel** under `app/extension/entrypoints/sidepanel` (Chrome `side_panel` / Firefox `sidebar_action`), opened from the toolbar action via `openPanelOnActionClick`. It replaced the former toolbar popup, which is removed. The panel docks beside the page and reflows it (never overlaying YouTube) and can be collapsed.
- Panel markup is static in `index.html`: a labeled top tab bar — Watch · Study · History · Account — over a persistent "now playing" header and scrollable view sections. **Watch is state-driven**: inside one tab it swaps between an unsupported-page notice, an inline sign-in prompt, the generation setup (compact language-pair card with an expandable picker, layer chips, generate button), a named-stage progress checklist, and the ready transcript (search + cue list + a Regenerate toggle that re-opens setup). `main.ts` bootstraps typed DOM handles (`dom.ts`), event wiring, and background messages; feature renderers live under `entrypoints/sidepanel/render/`, view labels in `view-model.ts`, tab/view switching reuses `tabs.ts` (`setupTabs`/`showTab` over `data-tab`/`data-panel`), timing persistence in `timing-control.ts`, and `utils/panel/view-state.ts` (`selectDefaultView`) always opens Watch, since its internal state replaces the old tab-teleporting defaults.
- Panel CSS is the marketing site's "ink & marker" system on its night palette (`entrypoints/sidepanel/style.css`, tokens mirroring `app/backend/public/css/site/tokens.css`): `#0e0e0e` ground with faint ruled-notebook lines, bone-paper text, single `#d83b3b` crimson accent, hard borders with an offset-shadow primary button, `//`-prefixed mono micro-labels, and bundled Bricolage Grotesque / Schibsted Grotesk / Spline Sans Mono (`@fontsource/*`). The on-video overlay keeps its own Geist + IBM Plex Mono files under `public/fonts` via `web_accessible_resources`.
- The in-page YouTube overlay shell is exported from `app/extension/utils/overlay.ts` into an isolated Shadow DOM host. Overlay render functions, shared types, and Shadow DOM styles live under `app/extension/utils/overlay/`.
- The content script binds ready tracks to the page's primary `<video>` element, resolves browser `TextTrack` cue changes back to the matching API cue, and avoids replacing overlay HTML when rendered content has not changed.
- The overlay renders a Shadow DOM language rail with source-token cards, cue timing, optional selected-target cue translation, optional romanization/gloss metadata, hover preview, click/tap pinned token detail, scoped blur/reveal study controls, cue replay, cue copy, keyboard shortcut status, and caption size/density/contrast preferences. Token-card reveal includes the token text plus that token's romanization when present; the full cue romanization line and translation line reveal independently on their own hover/focus. The rail, token cards, and popovers share the black + crimson brand palette (crimson cue timing, token hover/pin) with a high-contrast red/white theme variant.
- The transcript lives in the side panel as the Watch tab's **ready state** (`utils/panel/transcript.ts` renderer + `entrypoints/sidepanel/transcript-view.ts` controller): a searchable cue list with jump/replay (which seek the video), copy, and a save placeholder. When romanization is enabled and a cue's tokens carry per-word readings, each word renders with its romaji riding above it (the site's player-mock motif); otherwise the row falls back to the plain source line with a whole-line romanization. The content script relays the playing cue to the panel through the background hub (`content.activeCueChanged` → `background.activeCueChanged`), so the panel highlights and auto-scrolls to the active cue live; the panel's jump/replay round-trip back through the background (`panel.seekToCue` → `background.seekToCue`) to seek the bound video. The on-video overlay no longer renders a transcript — it shows only the caption rail and word card.
- The content script owns YouTube-page keyboard shortcuts for replay, previous/next cue navigation, translation visibility, source-word blur, hover pause, focusing the side-panel transcript, cue copy, and the Phase 02 save-current-cue placeholder. Shortcut dispatch ignores editable targets.
- The content script temporarily pauses the active YouTube video when a source token is hovered or focused if the local Study setting is enabled. It resumes playback when the token loses hover/focus, or as a fallback when the pointer leaves the rail, only if the extension caused the pause. Blank rail hover and manual video pause do not reveal blurred text.
- The overlay calls the background script for on-click token enrichment when a token only has transcript/romanization data, then re-renders from the patched backend track.
- Panel content map: **Watch** owns the whole generation loop — language pair + layer chips (Translation / Romanization / Word cards; the single source of truth for `showTranslation`/`showRomanization`/`fullTrackEnrichment`), the generate button with a plan-minutes note and privacy copy, backend-synced progress rendered as a named-stage checklist (`stageTimeline`), an error banner, and the ready transcript. The now-playing header shows the active tab's real video title (`pageTitle` on `PanelState`, stripped of YouTube chrome) over duration and language route. **Study** keeps caption display (show overlay, position, caption size, density, contrast, gloss, timing delay with reset), active-recall blurs (source/romanization/translation, hover-pause), keyboard shortcuts (enable toggle + help list), and a This-device zone (language defaults summary, clear-local-state). **History** (formerly Jobs) lists public-safe jobs grouped by Videos/Shorts as video-first cards: linked title, plain-word status pill (Queued / Generating · % / Ready / Failed), compact meta line, current-stage or error message, and Retry/Open-video actions. **Account** keeps sign-in/out, plan facts, feature availability, billing denial copy, and the usage meter. The panel stays responsive down to 320px.
- The panel exposes a manual subtitle timing delay from -10s to +10s. Dragging the range updates local display immediately and persists the setting on a short debounce; number/reset controls commit immediately. The content script applies the setting locally by rebinding the generated WebVTT track with shifted cue timings.
- The Laravel web app now serves the beta SaaS website and account surface from server-rendered Blade pages. Public pages cover home, `/extension`, pricing, language coverage, how it works, FAQ, privacy, terms, support, `robots.txt`, and `sitemap.xml` with canonical and social metadata; `/desktop` redirects to `/extension` for old links. Authenticated pages show plan, usage, Stripe-hosted billing actions, extension connection state, recent jobs, and owner-scoped public-safe job detail pages. Website CSS is loaded from `app/backend/public/css/site.css`, which imports split files under `app/backend/public/css/site/`; repeated Blade UI lives under `app/backend/resources/views/components/`. The homepage uses a scoped Hermes-inspired black-theme landing layout from the user-supplied design document; the remaining website/account visual direction stays Stitch-led dark academia.

## Expectations

- Keep the WXT extension bootable from the documented `app/extension` package commands.
- Add browser-driven validation for important user journeys.
- Capture screenshots or videos for UI fixes and visual regressions.
- Keep DOM state, routes, errors, and network failures legible to agents.
- Keep privacy and failure copy visible in the panel or overlay when video-derived audio/text leaves the browser or generation fails.
- Keep playback sync listeners direct and inspectable; add YouTube DOM fallbacks only after a concrete failure.
- Prefer reusable components once a pattern repeats.

## Scope Discipline

- Write non-goals for each meaningful feature.
- Prefer the smallest end-to-end slice that proves the workflow.
- Capture open product questions in execution plans instead of burying them in code.

## Feedback Loop

When user feedback changes direction:

1. Update the relevant product spec.
2. Update acceptance criteria in the active plan.
3. Add quality or regression checks if the feedback reveals a repeated issue.

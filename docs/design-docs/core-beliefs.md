# Core Beliefs

- Human time and attention are scarce.
- The repository is the durable memory for agents.
- A short map beats a long manual.
- Missing agent capability should become a tool, doc, test, lint, or template.
- Boundaries should be enforced mechanically where possible.
- Plans, validation evidence, and quality scores should be versioned.
- Continuous cleanup is cheaper than periodic large rewrites.
- Agents should be able to inspect the system they are asked to change.
